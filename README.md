# 🚀 React Hooks & Utility Projects

A comprehensive collection of 8 practical React.js projects built using Vite. This repository covers essential React concepts, state management techniques, lifecycle hooks, and API integrations.

---

## 📌 Projects Included

| # | Project Name | Key React Concepts & Hooks Covered |
|---|---|---|
| 01 | **[Counter App](./01-counter-app)** | `useState`, basic state manipulation & event handling |
| 02 | **[Todo List](./02-todo-list)** | Arrays state management, CRUD operations, immutability |
| 03 | **[Character Counter](./03-character-counter)** | Derived state, string manipulation, RegEx |
| 04 | **[Timer / Stopwatch](./04-timer-stopwatch)** | `useEffect`, `setInterval`, cleanup functions & memory leak prevention |
| 05 | **[Accordion FAQ](./05-accordion-faq)** | Conditional rendering, single-active item toggle logic |
| 06 | **[Tabs Component](./06-tabs-component)** | Dynamic content rendering, active state navigation |
| 07 | **[Weather App](./07-weather-app)** | `async/await`, REST API integration (Open-Meteo), loading & error states |
| 08 | **[Food Recipe Finder](./08-food-recipe-app)** | Complex API handling (TheMealDB), Master-Detail view pattern, CSS Grid |

---

## 🛠️ Tech Stack & Tools

* **Library:** React.js
* **Build Tool:** Vite
* **Styling:** CSS-in-JS / Inline Styles (Dark Theme System)
* **API Handling:** Fetch API with Async/Await
